## auto-hide-empty-elements (Feature) - COMPLETED

### Task completed
PRD: auto-hide-empty-elements
Text elements with all-empty token interpolations auto-hide in PDF output. Toggle "Show when empty" overrides this per element.

### Key decisions
- showWhenEmpty property on TemplateElement (optional, defaults to false = auto-hide)

## min-height-property (Feature) - COMPLETED

### Task completed
PRD: min-height-property
All Style Editor elements now have minHeight property with modes: None, Fixed, Auto, Percentage.

### Key decisions
- Added minHeightModeSchema (none, fixed, auto, percentage) to template types
- minHeightMode defaults to 'none' (no constraint) for backward compatibility
- minHeightValue (points) used when mode='fixed', minHeightPercent when mode='percentage'
- Auto mode uses calculateAutoHeight for containers, estimateTableHeight for tables, position.height for others
- Applied as Math.max(calculatedHeight, minHeight) at end of calculateEffectiveHeight
- Percentage is relative to parentHeight (or pageHeight if no parent)

### Files changed
- packages/shared-types/src/template.ts: Added minHeightModeSchema, minHeightMode/minHeightValue/minHeightPercent to TemplateElement
- packages/shared-types/src/layout-engine.ts: Added calculateMinHeight(), applyMinHeight(), integrated into calculateEffectiveHeight()
- apps/web/src/components/style-editor/PropertiesPanel.tsx: Added Min Height dropdown with mode selector + value inputs
- apps/web/src/components/style-editor/predefined-elements.ts: Added minHeightMode to defaultPositioningFields

### Notes
- Build passes. PDF generator uses layout engine which auto-applies minHeight constraint
- All element types supported: text, tables, divider, rectangle, logo, layout_container
