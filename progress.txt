## invoice-preview-using-stale-template-data (Bug Fix) - COMPLETED

Root cause: InvoicePreviewPopover used cached Convex templates (via useTemplates hook) but Style Editor uses Zustand store for instant updates. When editing a template in Style Editor, then opening Invoice Preview, stale data appeared.

Solution: Added check in selectedPreviewTemplate useMemo - if viewing template currently being edited (comparing storeTemplateConvexId === previewStyleId), use storeTemplate from Zustand instead of cached Convex version.

Files changed:
- apps/web/src/components/invoice/InvoicePreviewPopover.tsx
  - Added import for useTemplateStore
  - Added hook calls to get currentTemplate and getConvexTemplateId from store
  - Updated selectedPreviewTemplate useMemo to check for active Style Editor template

Build: PASSED (TypeScript compilation successful via turbo)
Note: Test/lint infra issues (missing rollup native module, eslint config) - pre-existing, not related to changes
