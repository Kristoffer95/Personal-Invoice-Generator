## STYLE-014: Canvas Container element

Added Canvas Container to style editor - layout container with canvas width/height modes.

Key decisions:
- Purple theme (#9333ea) for visual distinction from blue Column and green Row containers
- widthMode: 'canvas' and heightMode: 'canvas' to fill entire printable page area
- Column layout direction as default (same as root container)
- Zero padding and gap for full-page coverage
- Maximize2 icon to represent full-page behavior
- Position set to 0,0 with 0 dimensions (overridden by canvas mode)

Files changed:
- apps/web/src/components/style-editor/predefined-elements.ts - Added Canvas Container element
- apps/web/src/components/style-editor/predefined-elements.test.ts - Added tests for Canvas Container
