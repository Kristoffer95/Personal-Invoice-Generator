## PRD Item 4: Style Editor Bug - Justify Content in Row

### Task completed
Fix justify-content property not working correctly in Row elements

### Key decisions and reasoning
- Root cause: Layout engine (`layout-engine.ts`) wasn't implementing justify-content at all - just sequentially stacking children
- Added 'space-evenly' to justify schema (was missing per PRD requirements)
- Rewrote `calculateContainerChildPositions()` with two-pass algorithm:
  1. First pass: Calculate total content size and child dimensions
  2. Second pass: Apply justify-content distribution (start offset + gap calculation)
- Updated `TemplateElement.tsx` preview to include justifyContent and alignItems CSS for visual feedback
- Updated `PropertiesPanel.tsx` to include 'Space Evenly' option in dropdown

### Files changed
- packages/shared-types/src/template.ts (added 'space-evenly' to justifySchema)
- packages/shared-types/src/layout-engine.ts (complete rewrite of calculateContainerChildPositions)
- apps/web/src/components/style-editor/TemplateElement.tsx (added justifyContent/alignItems to container preview)
- apps/web/src/components/style-editor/PropertiesPanel.tsx (added Space Evenly option)
