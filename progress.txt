## Completed Tasks

### Style Editor - Height Options (PRD Item 1)
- Added heightMode schema: fixed | auto | percentage
- Added heightPercent field (0-100) for percentage mode
- Updated layout-engine to calculate heights dynamically:
  - Fixed: uses element.position.height
  - Auto: calculates from children + padding + gaps
  - Percentage: relative to parent or page height
- Added UI controls in PropertiesPanel for height mode selection
- Updated TemplateElement.tsx to show height mode indicator
- Disabled height resize handle for auto/percentage modes
- Files changed:
  - packages/shared-types/src/template.ts
  - packages/shared-types/src/layout-engine.ts
  - apps/web/src/components/style-editor/PropertiesPanel.tsx
  - apps/web/src/components/style-editor/TemplateElement.tsx
  - apps/web/src/lib/template-store.ts

### Style Editor - Row/Column Layout Options (PRD Item 3)
- Added flexBasis to schema (auto or number in pts)
- Removed max(1) on flexGrow/flexShrink for proportional sizing
- Added flex-wrap toggle to layout container UI
- Added flex item controls for relative-positioned children:
  - flexGrow, flexShrink, flexBasis inputs
  - alignSelf selector (inherit/start/center/end/stretch)
- Updated layout-engine with full flexbox distribution:
  - Uses flexBasis for base main-axis size
  - Distributes positive free space via flexGrow
  - Shrinks via weighted flexShrink when negative
- Files changed:
  - packages/shared-types/src/template.ts
  - packages/shared-types/src/layout-engine.ts
  - apps/web/src/components/style-editor/PropertiesPanel.tsx

### Style Editor - CSS Grid Support (PRD Item 7)
- Added displayMode to layoutConfigSchema: 'flex' (default) | 'grid'
- Added gridConfigSchema with:
  - templateColumns: string (e.g., "1fr 1fr 1fr", "100px auto 1fr")
  - templateRows: optional string
  - columnGap/rowGap: number (pts)
- Added grid item properties to elements: gridColumn, gridRow
  - Supports "1 / 3", "span 2" syntax
- Updated layout-engine with grid calculation:
  - parseGridTemplate(): parses fr, px, %, auto units
  - parseGridLine(): handles placement specs
  - calculateGridChildPositions(): positions children in grid cells
  - Auto-placement for children without explicit position
- Added UI controls in PropertiesPanel:
  - Display mode selector (Flexbox/Grid)
  - Grid columns/rows template inputs
  - Column/row gap controls
  - Grid item placement controls for children
- Files changed:
  - packages/shared-types/src/template.ts
  - packages/shared-types/src/layout-engine.ts
  - apps/web/src/components/style-editor/PropertiesPanel.tsx
